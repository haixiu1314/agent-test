# AgentTestLab

AI 智能体质量测试与安全审计平台。更新：2026-11-08。

## 启动

在项目根目录执行一个命令，启动前后端并显示访问网址：

```powershell
cd E:\Project-xhb\ai-test
npm run dev
```

- 网页：<http://127.0.0.1:5173>
- API 文档：<http://127.0.0.1:8000/docs>
- 健康检查：<http://127.0.0.1:8000/health/ready>

按 Ctrl+C 停止本次启动的服务。MySQL 保持运行。若 PowerShell 阻止 npm.ps1，可使用 `npm.cmd run dev`。端口占用时请先停止自己的旧启动终端。

完整手工验收可改用 `npm run dev:verify`，同一终端额外启动8001非AI协议目标。不要同时运行两种启动命令。

## 用户功能

注册并登录自己的账号即可使用项目、Agent接入、测试用例、任务执行、知识库、安全测试、轨迹审计、质量报告、AI用例生成、模型配置和企业助手演示。

“个人中心”位于 `/management`，只保留账号密码修改及本人的操作日志，日志分页展示并支持表格内滚动。用户列表和角色调整入口已移除。历史账号的个人日志也只显示自己的记录。

侧边栏固定在视口内，菜单过长时单独滚动，用户名和退出按钮保持在底部。切换模块时高亮块平滑移动，导航文字不显示下划线。系统遵循浏览器的减少动画设置。

## 模型配置

打开 `/models`，填写配置名称、用途、模型接口URL、模型名称和API密钥。眼睛按钮控制本次输入的显示，密钥保存时加密，历史密钥不回显；每个账号只管理自己的配置。

点击“测试”会真实请求当前模型：聊天测试使用单字符输入、最多1个输出token且不自动重试；向量测试使用单字符输入。超时等参数由系统固定，不再提供参数调节。测试通过后可保存，修改内容后需重新测试。连通性通过仅说明接口可用，不代表业务答案质量已通过评估。

目标 `localhost:3306/agenttest` 的认证此前返回1045，尚未切换。可选择：
