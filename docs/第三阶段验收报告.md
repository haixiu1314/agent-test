## 本轮发现并修复的问题

1. 中断任务只能重跑，无法继续：加入 interrupted 恢复路径，保留完成结果，只重置中断条目。
2. 执行器外层异常可能留下 running 结果：异常恢复时把相应条目标记为可追查的异常。
3. 恢复执行可能累积旧轨迹/评估：重试中断条目前清理该条旧事件与评估记录，保留已完成用例。
4. 运行时模型驱动旧迁移：改成固定的 Alembic 建表操作，并在真实临时 MySQL 验证升降级。
5. 提前编写的项目删除保护引用尚未创建的知识表：第三阶段仅检查已发布任务表，真实浏览器项目删除回归通过。
6. Agent 编辑表单会丢失新映射、写回固定适配器：补齐字段与适配器选择，保持保存内容一致。
7. 默认系统 pytest 临时目录拒绝访问：使用项目 `.local` 的显式 basetemp，关闭无关自动插件；未扩大系统目录权限。
8. 旧启动脚本绕过独立依赖：统一使用 run_module.py；锁定当前 143 个项目独立安装包。锁文件含此前安装的后续可选库，安装存在不代表功能已交付。
9. 重启测试曾按未指定顺序的结果首条判断：改为定位实际中断条目，最终全量通过。
10. 取消后完成计数容易误解：页面补齐取消数量与说明。
