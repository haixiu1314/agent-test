## 已发现并修复的问题

1. 默认 pip 缓存写入反复卡顿。用 faulthandler 定位到缓存临时文件创建；使用 `--no-cache-dir` 完成安装，无需关闭 TLS。
2. 项目 MySQL 初始化时 skip-name-resolve 导致 root@localhost 无法通过 127.0.0.1 完成初始引导。移除该配置，生成随机管理员及项目账号后完成初始化。
3. Element Plus 下拉选中层截获输入框指针。调整 pointer-events，浏览器流程通过。
4. 超时框 min=0.1、默认 step=1，使默认值 15 不符合原生校验。设置 step=0.1，保存成功。
5. 长配置弹窗和过渡动画干扰操作与截图。内部滚动，截图等待对话框及临时消息消失。
6. 平板登录标题出现单字尾行。精简标题，重新生成三种尺寸截图。
7. MySQL 端口已关闭但进程尚未释放数据目录，快速重启发生占用错误。停止脚本等待进程退出，启动脚本等待并检查就绪；再次冷重启成功。原有历史错误日志保留，不冒充从未发生。
