## 4. 已发现并修复的问题

1. RAGAS 0.4.3 与 langchain-community 0.4.2 的导入不兼容：固定兼容版本 0.4.1，补齐 dataclasses-json，旧元数据可逆重命名，pip check 及三种实际算法测试通过。
2. 失败索引的部分向量可能混入查询：在向量查询前限定已索引文档 ID；删除外部失败时不丢元数据。
3. 同库同步/异步请求可能相互穿插：采用共享线程锁进行短时原子准入，工作流结束释放忙碌标志。
4. 普通日期容易误当过期：仅有效期标签产生过期候选，其余日期显示普通提示；冲突也不能仅依据相似度。
5. 模型生成可能编造来源、重复或少题：验证结构、数量、不同问题及来源 ID，草稿需保存后评估。
6. 评分失败可能丢失已取得回答：调用前登记样本，逐步保留命中、回答及错误码，工作流超时保存部分结果。
7. 大文本测试参数默认 ID 导致 Windows 输出过长：改用短参数 ID；前端索引类型错误、标签切换遗留提示及截图动画也已修复。
8. 后端重启曾重复绑定 8000：停止本任务原服务后启动最终服务，成功启动并验收；该启动冲突不计作业务请求错误。最终日志没有未处理异常。

## 5. 当前限制与遗留问题

真实验收阻塞：模型密钥尚未配置；Docker/Milvus 尚不可用。没有用模拟向量、固定冲突结论或静态分数填补这部分。用户补齐后运行真实脚本并检查源证据，失败则继续修复；当前不能将阶段四标为全部验收通过。

产品当前限于单进程运行，知识库锁不是跨进程锁。每次质量检查最多 300 块，语义最多 20 对，规则近似比较前 500 字符；AI 生成上下文最多 30 块；问题集最多 20 题。质量语义与评估工作流预算 180 秒。模型输出可能波动，阈值 0.7 是项目提醒规则，Answer Relevancy 使用 strictness=1 控制调用量。

单文件 500000 字节、每库 100 文档；PDF 不支持 OCR/加密，DOCX 页码不是 Word 实际分页。分块正文仍为 MySQL 明文。部分外部请求在本地取消后仍可能执行，因此使用状态过滤和清理重试，不宣称跨 MySQL/Milvus 原子事务。

RAGAS 兼容 API 有弃用警告，需要在未来依赖升级时迁移并回归。生产主包约 1.107MB（gzip 367KB），RAG 页面已独立懒加载，但共享主包仍有体积提示。CDP 技能 inspector 未通过，已用实际浏览器替代验证但不冒充其结果。
