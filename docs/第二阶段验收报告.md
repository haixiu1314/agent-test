## 本轮修复

1. 并发修改可能覆盖：套件行锁与修订号校验，真实 MySQL 两个并发请求分别返回 201 和 409。
2. 导入可能留下半批数据：先解析/校验全部行，再在同一事务新增并保存快照。
3. 已保存草稿可能重复入库：锁定生成记录，检查已保存索引并拒绝重复。
4. 加密模型响应超过 TEXT：新增 MEDIUMTEXT 扩容迁移；长 Unicode 输入也单独扩容并实测保存读取。
5. 重启后运行状态可能停留“生成中”：单进程应用启动时将未完成调用标记为失败/中断。
6. 页面空模型选项显示为默认占位：改为明确的本地环境配置选项。
7. 删除分页最后一条后出现空列表：自动回到前一页。
8. 截图被临时提示条遮挡、测试定位混淆：等待提示条退出并精确定位错误区域。
