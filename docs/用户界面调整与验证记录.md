# 用户界面调整与验证记录

更新：2026-11-08。

## 本轮改动

1. 原“系统管理”改为“个人中心”，仅保留当前账号、修改密码和本人的分页操作日志。用户列表与角色修改接口已移除；旧账号查看日志也只返回自己的记录。
2. 清除登录页、侧边栏及相关页面中的开发阶段、交付与角色管理提示。
3. 侧边栏保持视口高度，菜单内部滚动，用户名和退出按钮固定在底部。导航无下划线，高亮块随模块切换平滑移动；遵循减少动画设置。
4. 修复全局label样式影响复选框导致的错位，检查安全测试、AI生成以及其余模块的窄屏布局。
5. 模型配置移除高级参数，只保留“测试”。聊天探测单字符输入、1个输出token上限、固定超时、不自动重试；向量探测单字符输入。密钥显隐和测试后保存仍可使用。

## 手工复核步骤

1. 在项目目录运行 `npm run dev`，登录自己的账号。预期：左侧出现“个人中心”，没有用户角色入口或开发阶段字样。
2. 进入个人中心查看日志、翻页并滚动。预期：日志只属于当前账号；左下用户名和退出按钮不随正文移出视口。
3. 依次点击安全测试、AI生成、模型配置。预期：导航没有下划线，高亮平滑切换，复选框文字与选框在同一行，窄屏可正常换行。
4. 进入模型配置。预期：没有温度、超时、输出token设置，只有一个“测试”按钮；填入自己的有效配置并测试后才能保存。失败应展示原因，不能冒充成功。
5. 将浏览器调为约390像素宽并打开菜单。预期：模块可访问、没有整页横向溢出、退出按钮可见。

模型连通测试经过本地HTTP协议服务验证，没有使用外部付费模型证明AI效果。真实LLM、Embedding、Milvus联合验收与JMeter仍待补验。数据库本轮未迁移，实际仍为127.0.0.1:3307/agenttestlab，不应在3306查找当前运行数据。

旧内部系统参数、存储及全局任务接口仍保留原权限约束供兼容使用，个人页面不调用；本轮未清空已有角色字段或历史业务数据。
