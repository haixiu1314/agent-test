# 个人模型与账号使用说明

更新：2026-11-08。项目目录：`E:\Project-xhb\ai-test`。

## 启动与登录

在项目根目录执行 `npm run dev`，打开终端显示的网址（通常 http://127.0.0.1:5173），注册并登录自己的账号。日常功能使用同一个网站和登录入口。

## 配置模型

进入“模型配置”，按以下顺序操作：

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 填写配置名称并选择用途 | 名称便于自己区分，用途与业务页面匹配 |
| 2 | 填写模型接口URL | 使用服务商OpenAI兼容基础地址，通常以 /v1 结尾；不追加 /chat/completions |
| 3 | 填写准确模型名称 | 使用服务商提供的模型ID，向量模型与聊天模型分别配置 |
| 4 | 输入API密钥，点击眼睛按钮 | 默认遮蔽；可查看本次输入，再点击恢复隐藏 |
| 5 | 点击“测试” | 系统真实调用接口；成功显示测试通过与耗时，失败显示可操作的原因 |
| 6 | 测试通过后保存 | “我的模型配置”出现新记录，刷新后仍存在，密钥输入清空 |
| 7 | 编辑已保存配置 | 密钥留空继续使用原值；更换内容后必须重新测试才能保存 |

聊天测试使用单字符输入、最多1个输出token、固定超时且不自动重试；向量测试使用单字符输入。页面没有温度、超时、输出上限等调节项。服务商可能有最小计费或推理费用，这个测试仅验证接口可用性，不能证明业务回答质量。

保存密钥时加密存储，列表不返回原始密钥。眼睛按钮只显示本次输入，不解密回显历史密钥。每个账号只能查看、编辑、测试和引用自己的模型配置。

保存后，在AI生成用例选择generation用途，在安全测试选择security用途，企业助手选择demo用途，质量评分选择judge用途，知识库按需选择rag和embedding用途。

## 失败时检查

| 提示 | 处理方式 | 预期结果 |
| --- | --- | --- |
| 缺字段或密钥 | 补齐名称、URL、模型ID及新配置密钥 | 能发起测试 |
| 密钥或权限错误 | 检查服务商密钥与模型访问权限 | 错误不会显示为通过 |
| 路径或模型不存在 | 检查基础地址，避免重复路径，核对模型ID | 修正后重新测试 |
| 限流或额度不足 | 检查服务商余额和限制 | 恢复后重测 |
| 网络或超时 | 检查网络及服务商状态 | 不会自动无限重试 |

密钥不要发送到聊天或放入截图。连通测试可能消耗少量额度。

## 个人中心

打开“个人中心”（`/management`）。页面仅显示当前账号、修改密码和自己的操作日志。

| 操作 | 预期结果 |
| --- | --- |
| 输入错误旧密码修改 | 明确拒绝，密码不变 |
| 输入正确旧密码与10–128字符新密码 | 修改成功；退出后用新密码可登录，旧密码不能新登录 |
| 查看操作日志并翻页 | 每页最多50条，只显示当前账号操作；表格内部滚动 |
| 在日志较多时滚动页面 | 侧边栏用户名和退出按钮仍在视口底部 |
| 点击不同模块 | 高亮块平滑移动，导航文字没有下划线 |

修改密码后其他已登录会话可能持续到原令牌过期。需要结束当前会话时点击“退出登录”。
